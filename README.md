TUD ship is a collection of computational tools from the numerical ship-hydrodynamics group of the TU Delft.
All tools are build on top of MFEM.

* For building instructions, see the file [INSTALL](INSTALL), or type "make help".

* Copyright and licensing information can be found in files [LICENSE](LICENSE) and [NOTICE](NOTICE).

* For information on the MFEM library, see the file [README-MFEM](README-MFEM).
